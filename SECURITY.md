# Política de seguridad y confidencialidad

Este proyecto se diseña para tratar información confidencial: **todo es local** y no hay
telemetría. Los principios están en [docs/PRIVACIDAD.md](docs/PRIVACIDAD.md).

## Cómo informar de un problema

Abre un *issue* **sin incluir** audio, texto dictado ni datos personales. Si el problema afecta a
la confidencialidad, descríbelo de forma general y se contactará contigo en privado.

## Qué no debe subirse nunca al repositorio

Audio, registros, `config.local.json`, frases propias (`pruebas/*.local.txt`), modelos
descargados y capturas con datos personales. El `.gitignore` ya excluye la mayoría.
